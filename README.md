
# Smart Vibration Fault Detector

My first ECE project using Verilog HDL.

## Description
This project classifies vibration input as NORMAL or ABNORMAL.

## Threshold
- Below 50: NORMAL (0)
- 50 or above: ABNORMAL (1)

## Tools
- Verilog HDL
- EDA Playground
- Icarus Verilog

## Test Results

| Vibration Input | Output |
|---:|---|
| 20 | NORMAL |
| 40 | NORMAL |
| 50 | ABNORMAL |
| 75 | ABNORMAL |
| 100 | ABNORMAL |
